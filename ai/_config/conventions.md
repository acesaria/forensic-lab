# Conventions

## Naming

- Stage folders are numbered and ordered.
- Every stage must contain:
  - `CONTEXT.md`
  - `references/`
  - `output/`

## Output notes

Every completed task should leave a short markdown note in that stage's `output/`.

Recommended format:
- task
- files changed or artifacts produced
- validations performed
- blockers
- next recommended stage

## Style

- Keep outputs factual and concise.
- Prefer bullet lists over long prose.
- Do not copy large code blocks unless required.
- Reference exact file paths whenever possible.
