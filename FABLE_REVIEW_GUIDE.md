# FABLE_REVIEW_GUIDE.md

Start architecture and methodology review from:

- `PROJECT_CONTEXT.md`
- `AGENTS.md`
- `README.md`
- `cli.py`
- `docs/metrics_methodology.md`
- `docs/canonical_pipeline_schema.md`
- `matcher/`
- `detectors/`
- `orchestrator/canonical/`
- `orchestrator/adapters/`
- `orchestrator/core/`

Scenario internals are not needed for architecture or methodology review. Do
not inspect scenario implementation files unless explicitly asked.

Focus review on methodology, evidence layers, metrics semantics, module
duplication, documentation clarity, and simplification opportunities.
