# agent_tasks

Small, isolated task cards for scheduled or overnight agent work.

Rules:

- One task = one focused audit or change.
- Each card must be copy-pasteable into Codex, Claude, or Copilot.
- Include objective, scope, files to inspect, forbidden changes, expected output, and done criteria.
- Do not ask for a whole-repo rewrite.
- Read `PROJECT_CONTEXT.md` and `AGENTS.md` before starting any task.

Use `backlog/` for prepared cards and `runs/` for local run notes or outputs.
`runs/` is intentionally ignored.
